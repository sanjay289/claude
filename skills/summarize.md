---
name: summarize
description: Condense a long piece of text or file contents into a short, faithful summary.
---
When summarizing:
- Preserve concrete facts (numbers, names, dates) over general impressions.
- State the main point in the first sentence.
- Use plain prose, not bullet points, unless the source is a list.
- Never add information that isn't in the source.
- Target 3-5 sentences unless the user asked for more or less detail.
